## Шүүгчдийн магадгүй асуултад товч хариу
- **Deploy хийгдсэн үү?** Үгүй, локал демо. Нийтэд нээхэд аюулгүй биш dev-direct горим байгаа тул санаатайгаар байршуулаагүй.
- **erxes-тэй яаж холбогддог вэ?** Албан ёсны `@erxes/api-shared` SDK дээр бичигдсэн plugin, Federation 2 subgraph, Redis бүртгэл — локалд баталгаажсан; hosted gateway дээр операторын суулгалт хүлээгдэж байна.
- **AI юу хийдэг вэ?** SOS хадгалагдсаны дараа асинхроноор Gemma 4 (OpenRouter) → Zod шалгалт → зөвхөн багшид санал. Бодит нотолгоо 15:42 (`docs/ai-proof/latest.json`). Хязгаар дүүрвэл FAILED/QUOTA гэж шударгаар харуулна.
- **QR яаж ажилладаг вэ?** Код дотор зөвхөн zone + HMAC гарын үсэг; сервер шалгана; хуурамч код татгалзагдана. Утасны камераар бодит туршилт хийгдээгүй.
